# BCI 가상 오른팔

카메라로 찍은 실제 팔·손의 움직임을 물리 시뮬레이션 오른팔로 바꾸어, 휴대폰을 끼운 DIY VR 기기로 보는 웹 프로그램입니다.
"BCI 기술을 활용한 아바타 제작 가능성 탐구"의 아바타 시각화 부분입니다.

## 사용 방법
1. **크롬북**: 배포 주소를 열고 `카메라와 시뮬레이션`을 고릅니다. 화면에 4자리 코드가 나옵니다.
   - `카메라 켜기` → 상체와 오른팔, 손이 모두 보이게 앉습니다.
   - `팔 쭉 편 기준`, `팔 끝까지 굽힌 기준`, `편 손 기준`, `주먹 기준`을 각 자세에서 한 번씩 눌러 내 몸에 맞춥니다.
   - `휴대폰 VR 화면 미리보기`를 누르면 크롬북에서도 휴대폰과 같은 양안 분할 화면을 볼 수 있습니다. 휴대폰이 연결되어 있으면 휴대폰 사용자의 시선과 렌즈 설정을 그대로 따라갑니다.
2. **휴대폰**: 같은 주소를 열고 `VR로 보기`를 고른 뒤 코드를 입력해 연결합니다.
   - 렌즈 보정 슬라이더를 VR 기기에 맞추고 `VR 시작`을 누른 뒤 가로로 눕혀 VR 기기에 넣습니다.
   - VR 안에서 탭: 정면 맞추기 / 1초 누르기: 설정 화면

## 팔 모델
| 항목 | 값 |
|---|---|
| 어깨–팔꿈치 : 팔꿈치–손끝 | 1 : 1 (30 cm : 30 cm) |
| 손끝–손목 : 손목–팔꿈치 | 2 : 3 (12 cm : 18 cm) |
| 움직이는 관절 | 팔꿈치 굽힘·폄 0–145°, 손목 고정 |
| 아래팔 자세 | 90° 돌린 중립 자세 (손바닥이 몸 쪽, 엄지가 앞) |
| 손 | 다섯 손가락 동시에 쥐기·펴기 |
| 보기 모드 | 피부 / 근육·뼈 / 뼈·관절 |

근육 활성도는 측정값이 아니라 물리 모델로 거꾸로 계산한 추정값입니다.

## 카메라 인식 방식
- 팔꿈치 각도: MediaPipe Pose의 어깨·팔꿈치·손목 3D 좌표로 두 벡터의 사이각을 계산 → One Euro 필터로 떨림 제거 → 개인 기준(편 팔/굽힌 팔)으로 0–140° 보정
- 손 쥐기: MediaPipe Hand의 네 손가락 세 마디 굽힘각 합의 평균 → 개인 기준(편 손/주먹)으로 0–100% 보정
- 한 프레임에 60° 넘게 튀는 값은 다음 프레임에서 확인될 때만 반영

## 사용 기술
- [three.js](https://threejs.org) r128: 3D 렌더링, 양안 분할, 렌즈 왜곡 보정 셰이더
- [MediaPipe Tasks Vision](https://developers.google.com/mediapipe): 팔(Pose)·손(Hand) 관절 인식
- [PeerJS](https://peerjs.com): 크롬북 → 휴대폰 실시간 전송 (WebRTC)
- GitHub Pages: 배포 (카메라·자이로·WebRTC에 필요한 https 제공)

## 참고
- 학교 와이파이가 기기 간 직접 연결(P2P)을 막으면 연결이 안 될 수 있습니다. 두 기기를 같은 휴대폰 핫스팟에 연결해 보세요.
